# Spec Delta

## MODIFIED Requirements

### Requirement: The container ends when either service ends

Когда приложение завершается без сигнала остановки, контейнер SHALL корректно остановить встроенный сервер PostgreSQL и завершиться с кодом выхода приложения. Исключение — код выхода восстановления 75, которым приложение завершается после подготовки бэкапа Databasus к восстановлению. На этот код контейнер SHALL снова запустить приложение, не останавливая встроенный PostgreSQL. Если сигнал остановки пришёл после выхода с кодом 75 и до нового запуска, контейнер SHALL NOT запускать приложение снова, а SHALL корректно остановить встроенный PostgreSQL и завершиться с ненулевым кодом. Перезапущенное приложение SHALL получать сигналы остановки так же, как первое. Когда встроенный сервер PostgreSQL завершается во время работы приложения, контейнер SHALL остановить приложение и завершиться с ненулевым кодом.

#### Scenario: Application exits on its own

- **WHEN** процесс приложения завершается с кодом, отличным от 75, а сигнала остановки контейнер не получал
- **THEN** контейнер завершается с кодом выхода приложения
- **AND** остановленный каталог данных сообщает состояние кластера `shut down`

#### Scenario: Application exits with the recovery exit code

- **WHEN** процесс приложения завершается с кодом 75, а сигнала остановки контейнер не получал
- **THEN** контейнер снова запускает приложение
- **AND** процесс встроенного PostgreSQL тот же, что и до выхода приложения, и не перезапускался

#### Scenario: Stop signal before the relaunch

- **WHEN** приложение завершилось с кодом выхода восстановления, и до нового запуска контейнер получает `SIGTERM`
- **THEN** приложение больше не запускается, а контейнер завершается с ненулевым кодом
- **AND** остановленный каталог данных сообщает состояние кластера `shut down`

#### Scenario: Stop signal after the relaunch

- **WHEN** приложение перезапущено после кода выхода восстановления, и контейнер получает `SIGTERM`
- **THEN** контейнер передаёт сигнал перезапущенному приложению, дожидается его выхода и только потом останавливает PostgreSQL
- **AND** остановленный каталог данных сообщает состояние кластера `shut down`

#### Scenario: Embedded database exits unexpectedly

- **WHEN** встроенный сервер PostgreSQL завершается во время работы приложения
- **THEN** процесс приложения останавливается
- **AND** контейнер завершается с ненулевым кодом
